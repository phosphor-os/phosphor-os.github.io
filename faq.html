Setting things up

First start: what do I set up?
  • WiFi (Settings › WiFi), or plug a network cable into the dock. Box art, updates and cloud saves need it.
  • Controllers: plug in USB ones; pair Bluetooth ones (next question). If the buttons are wrong, see Controllers.
  • Your games: put them in games/<system> on the SD card or on the NVMe / USB drive (the same folders MiSTer uses), then Settings › Look for games and Get box art and details.
  • Cores: Settings › Update All (or Update) gets them, as on any MiSTer.
How do I pair a Bluetooth controller?

Hold the SS1's BT button on the console, or open Settings › Bluetooth and choose Pair. Phosphor looks for 90 seconds; put the controller in pairing mode while it counts down:

  • 8BitDo: Start + Y (Switch mode) or Start + X (X-input);
  • Xbox: hold the pair button on top;
  • PlayStation: hold Share + PS until the light flashes;
  • Switch Pro: hold the sync button on top.

Paired controllers are listed below; press X twice on one to forget it, or Delete all pairings at the end of the list.

How do I pair the phone app or Phosphor for Windows?

Settings › Remote access, turn it on and choose Pair a device. Type the 6-digit code the TV shows into the app. Only paired devices get in, only on your home network.

How do I set up box art sources that need a login?

libretro, ArcadeDB and LaunchBox need nothing. ScreenScraper needs your free screenscraper.fr login, TheGamesDB a free API key, IGDB a free Twitch developer app. Type them into Phosphor for Windows (Settings › Box art), or put them in phosphor/config/scraper.ini on the SD card. Turn sources on or off and set their order in Settings › Box art sources.

How do I set up cloud saves?

Settings › Cloud saves › Storage place: your own WebDAV, SFTP or SMB share, or Google Drive, Dropbox or OneDrive (added from the phone app, which does the sign-in). After that, saves, save states and core settings go there after each game, with older versions kept. Getting them back is only on request, with a preview first. WiFi, Bluetooth pairings and passwords are never sent.

How do I set up RetroAchievements?

Settings › RetroAchievements › Account: log in once (only a login token is kept), then RetroAchievements cores › get updates. Games on those systems then start on the RetroAchievements cores. For Your progress, paste your Web API key from retroachievements.org › Settings › Keys.

How do I use a CRT?

Settings › Video › CRT mode puts Phosphor's own menu on the analog port at the TV's timing (240p, 288p, 480i, 576i, or 480p for VGA monitors). Pick the video profile for your cable on the same screen (RGHV, RGsB, SVID, YPbP) and set the DIP switches it names; the DIP switch table is below. A change you try goes back by itself unless you keep it, so a mode the TV can't show is never stuck.

How do I set up Repair all drives?

Plug a spare USB stick into the SS1 (exFAT, 1 GB free), then Settings › Storage › Repair all drives and choose it. Phosphor puts a copy of MiSTer's Linux on it (about 400 MB). From then on, Restart and repair all drives repairs the SD card and every other drive in one restart. Keep the stick plugged in or in a drawer; it's hidden from everything else (see below).

Controllers

How do controller mappings work?

There's one mapping per controller, MiSTer's own, and it's used everywhere: Phosphor's menus, MiSTer's menu and every core. MiSTer already knows most controllers (its built-in controller list), so they work straight away. For one it doesn't know, or to set one up your way, you map it once.

In Phosphor's menus, A, B, X and Y are always the buttons printed on your controller, by its layout (Xbox, PlayStation or Nintendo). Mapping it, or resetting the mapping, never moves them.

In Settings › Controllers each controller says which it uses: MiSTer's automatic mapping, or its own (custom) mapping.

How do I map my controller?
  1. Settings › Controllers, pick the controller, press A (Map buttons).
  2. Press each button the screen asks for. The drawing shows which one. It starts with the D-pad so MiSTer learns how the controller reports it.
  3. It's saved at the end. Select + Start cancels with nothing saved.
  4. Press Y (Test it) to check: every press lights up, and the tester shows what MiSTer receives.

Every change is backed up first (Backups on the same screen puts an earlier one back). X (Reset to automatic) goes back to MiSTer's built-in mapping. Left/right picks a different drawing if the one shown doesn't look like your controller; that only changes the picture and which printed button is A in the menus.

My controller or adapter isn't working, or isn't listed
  • Not listed in Settings › Controllers at all: try another USB cable (some only charge) and another port. For Bluetooth, pair it again. If it's an 8BitDo or an adapter with modes (X-input, D-input, Switch, macOS), switch to X-input or Switch mode and plug it in again.
  • Listed, but buttons are wrong or missing: map it (previous question). If the tester shows nothing for a button, the controller isn't sending it in this mode; try another mode.
  • Works in the menu but not in a game: check the core's own input settings in MiSTer's menu (in the game: menu button › MiSTer menu).
  • Original controllers in the front ports (SNAC) are handled by each core: look in the core's OSD settings. Settings › Front ports & memory cards shows what's plugged in.
  • Still nothing: it may need a Linux driver MiSTer doesn't have. Make a report (Settings › Diagnostics › X); it lists every controller the SuperStation sees and how. Post it in #help on the Phosphor Discord with the controller's or adapter's make and model. Adapters people have tested are added as they come.
My controller turns off by itself

Most wireless controllers sleep after a few minutes without input to save the battery. Press any button to wake it. 8BitDo controllers also switch off when the home button is held; Phosphor's in-game menu opens with a tap, so that never happens by accident.

How Phosphor works

What is Phosphor?

Unofficial custom firmware for the SuperStation One, built on mainline MiSTer and its Linux. It has three parts:

  • Phosphor, the menu you see on the TV;
  • phosphord, a small background service that keeps your library, box art, saves, backups and settings;
  • Phosphor for Windows, which talks to phosphord over your home network.

Cores, Update All and MiSTer's own menu keep working the way they always have.

Does Phosphor scan my games or download things by itself?

No. Looking for games, fetching box art and installing updates only happen when you choose them. Phosphor only goes online for the box art sources you pick, your own storage for cloud saves, and MiSTer's update servers when you run an update.

Where does the box art come from?

Six sources. libretro, ArcadeDB and LaunchBox need no account. ScreenScraper needs your free screenscraper.fr login, TheGamesDB a free API key, and IGDB a free Twitch developer app. You choose which ones are used.

Why look up box art on the PC instead of the SuperStation?

It's much faster. The PC fetches the pictures and makes the box art, then sends it to the SuperStation.

What are "Based on" links?

They tie a hack, translation or fan version to the game it's based on, so it can use that game's box art and details.

How do I shut down or restart safely?

Press Select + Start together anywhere in Phosphor, then choose Shut down safely or Restart. Shutting down this way marks the drives clean, so Windows won't ask to scan the card.

What happens if the power goes?

Phosphor notes what was going on (writing saves, a backup, an update) and checks or puts things back at the next start. The Power section of Diagnostics lists these events, with tips on what helps.

How do updates work, and can I go back?

Copy the update to phosphor/updates on the SD card (or send it from Phosphor for Windows), pick it on the TV and press Install. Phosphor keeps a copy of the version you had, so going back is one press. Your library, box art, saves and settings stay as they are.

Where did the screen filters go?

They're gone. The Video section now lets you try MiSTer's video settings (see Video).

Can I play games from the dock's CD/DVD drive?

Yes: PlayStation, Saturn, Mega-CD, PC Engine CD, Neo Geo CD, CD-i and 3DO discs, and MSU-1 / MD+ discs. Put the disc in and open Library › Disc: it's at the top as In the drive, with its name and box art. Press A to play it, Y to eject. Nothing starts by itself. Music CDs play in the music player (see below); DVDs aren't played. Phosphor for Windows and Android show the disc too and can start it on the TV. Settings › Discs turns it off. Disc support is by Anime0t4ku and bonna79.

Can it play music?

Yes, from the Music tile on the home screen, while no game is running. It plays albums from a Music folder on the SD card or a USB drive (FLAC, MP3, OGG, WAV), and music CDs in the dock's drive, with track names from MusicBrainz and covers from the Cover Art Archive. A CD can be copied to FLAC on the TV (Music › the CD › X). Phosphor for Windows sends your Steam soundtracks to it (Tools › Music › Steam soundtracks): it lists the ones Steam has installed on the PC, and nothing signs in to Steam. Control it from the TV, the remote, the phone app or the PC.

Does it do RetroAchievements?

Yes, for NES, SNES, Game Boy, GBA, N64, PlayStation, Mega Drive, Mega-CD, Master System, Game Gear, PC Engine and Atari 7800 games. Log in on the TV in Settings › RetroAchievements, then press Get the cores. Only a login token is kept on the SuperStation, never your password. Hardcore, pop-up position and the unlock sound are set there too, and Your progress shows your points and games (it needs your Web API key from retroachievements.org › Settings › Keys). This is odelot's MiSTer RetroAchievements work and the RetroAchievements team's rcheevos.

How do I get to MiSTer's menu during a game?

Press the menu button for Phosphor's in-game menu (back to the game, change disc, MiSTer menu, quit to Phosphor), then choose MiSTer menu (OSD) for MiSTer's own menu. There's no press-and-hold, so 8BitDo controllers, which turn off when the home button is held, are safe.

Phosphor for Windows

How do I pair it with my SuperStation?

On the TV, open Settings › Remote access, turn it on and choose Pair a device. The TV shows the address and a 6-digit code to type into Phosphor for Windows. If the router later gives the SuperStation a new address, the app finds it again on your network.

Why can't the app change WiFi, pairing or Bluetooth?

On purpose. A paired device could otherwise lock you out of your own SuperStation, so those can only be changed on the TV.

Why does the app's colour change?

It follows the accent and texture you picked on the SuperStation, so there's nothing to set twice.

What are "MiSTer & Linux backups"?

Phosphor for Windows keeps every version of the SuperStation's important files on your PC:

  • Settings: MiSTer.ini and its profiles, downloader.ini, Phosphor's settings, the network address, the name and the SSH settings;
  • System files: MiSTer itself, the menu core and Linux.

It checks every half hour while the SuperStation is on, and only copies what changed. They're in Settings › Power & updates › MiSTer & Linux backups.

A note says a file "looks reset by an update"

That settings file changed at the same time MiSTer Linux did, which usually means the update put it back to stock. The version from before is kept: put it back from MiSTer & Linux backups.

Are my WiFi password, SSH keys and logins backed up?

No, never. They stay on the SuperStation.

What happens when I put a file back?

The SuperStation checks that the file arrived whole, and keeps a copy of the one it replaces first. If it was a system file, the app tells you to restart.

Drives, repairs and updates: what Phosphor changes

What does Phosphor change on my SuperStation, and does any of it send data anywhere?

Nothing here goes online or sends anything anywhere. All of it is plain shell scripts and C you can read in the source. Phosphor keeps to:

  • /media/fat/phosphor/: the programs, your library, box art, settings, backups and logs;
  • its own marked block in linux/user-startup.sh (# phosphor: BEGIN / END) that starts it at boot and runs the safe shutdown;
  • a small ID file on each drive (phosphor/drive.id, next question);
  • a small hook in Linux's own /etc/usbmount and /etc/udev/rules.d that hides the repair stick (below). It only acts on a drive with a repair copy of Linux on it;
  • the repair lines in linux/u-boot.txt, only if you set up Repair all drives (below);
  • the video settings once per card (see Video).

It never moves, renames or deletes your games, saves or cores. phosphor/uninstall.sh takes it all off again.

What is the phosphor/drive.id file on my drives?

A few lines of text: a random ID for that drive, whether it's the SD card or a games drive, and when it was made. MiSTer names USB drives by the order they come up (/media/usb0, usb1...), so a stick plugged in first, or an NVMe drive that's slow to start, shuffles the numbers. The ID lets Phosphor's library recognise the drive under any number. Your games, play history, favourites and box art follow it, with no new scan. Delete it and Phosphor just makes a new one.

My games drive changed from usb0 to usb1. Are my games gone?

No. Nothing on the drive changed, only the number MiSTer gave it. Since 0.27.54 Phosphor's library follows the drive by its ID. Since 0.27.56 the repair stick, which caused most of these shuffles, never takes a number, so the dock's NVMe drive keeps usb0. For Console Mode, SS1 Tool's Drive guard keeps the games drive at usb0.

The dock's NVMe drive: oddities, and what Phosphor does about them

The dock's NVMe slot is a JMicron USB-to-NVMe bridge. It behaves in a few odd ways, and Phosphor handles each one:

  • An empty slot shows up as a phantom drive that never becomes ready and can hold up shutting down. Phosphor removes it after a minute (the SS1's own rule did it after 15 seconds, which also took away a real drive that was slow to start).
  • Stuck after a restart ("Unit Not Ready"): a restart keeps the dock powered, and the bridge can come back without its drive. Phosphor looks for a drive it has seen before again every 30 seconds for 3 minutes (0.27.55), and every restart now lets the USB devices go first (0.27.56). If it still isn't there, the TV says to unplug the SuperStation's power for 10 seconds, which always clears it.
  • A different drive number: MiSTer numbers USB drives in the order they come up, so the NVMe drive can be usb0 one day and usb1 the next. Phosphor's library follows it by its drive ID, and the repair stick no longer takes a number.
  • Gen 4 NVMe drives can make the SuperStation reboot by itself or show file system errors. Use a Gen 3 drive.
  • "Not shut down safely" after pulling the power: Shut down safely (Select + Start) first. If it happens, Settings › Storage › Repair all drives fixes the SD card and the NVMe drive in one restart.
The NVMe drive was missing after a restart

A restart keeps the dock powered, and its NVMe adapter (a JMicron bridge) can come up stuck ("Unit Not Ready"). Since 0.27.55 Phosphor looks for a drive it has seen before again every 30 seconds for 3 minutes, and stops the moment it's there. It never touches the dock while a drive is on it. If the drive still isn't back, the TV says to unplug the SuperStation's power for 10 seconds, which always clears it.

Why does a restart take a few seconds longer now?

Since 0.27.56 every restart is a safe one: from Phosphor, MiSTer's own menu, Update All or the downloader, a terminal, or a core that couldn't load. Before the restart, Phosphor's modules stop, every drive is flushed and made read-only, and the USB devices are let go. That's why the SD card no longer comes back "not shut down safely", and why Windows stops asking to scan it.

What is Repair all drives, and what does it put on my USB stick?

The SD card can't be repaired while MiSTer runs from it. Repair all drives (Settings › Storage) puts a copy of your SuperStation's own MiSTer Linux on a spare USB stick (about 400 MB, in phosphor/rescue). It also adds a few lines to the SD card's linux/u-boot.txt, starting phos_, that do nothing until you choose Restart and repair. Then one restart repairs the SD card, the NVMe drive and any other drives while nothing is using them, and starts Phosphor again with the results.

The copy is only made again when MiSTer's Linux changes (about 44 seconds). Turn off drive repair takes the lines and the copy away. A stick shared with SS1 Tool keeps both copies side by side (phosphor/rescue, ss1tool/rescue).

Where did my repair stick go? It's not in the drive list

Since 0.27.56 it's at /media/repair, read-only, the moment it's plugged in, and it never gets a /media/usbN. As a normal drive it got used for things it isn't for: Update All's downloader put dozens of empty games folders on one. Hidden and read-only, nothing writes to it except Repair all drives, which makes it writable only while it updates its own files. It's still repaired with every other drive. If something else did put files on it, Settings › Storage › Repair all drives lists them, with Move them to the games drive.

A drive is only treated as the repair stick if it has a repair copy of Linux on it, and never if it's the dock's NVMe drive.

What does update guard do? Does it change my updates?

It doesn't change your updates. It makes them safe to take back. Updates always run only when you start them.

  • Restore points. When you start an update from Phosphor (Update All, the downloader, a Phosphor update), update guard first saves the files it's about to replace: MiSTer, the menu core and the kernel, plus Linux itself if you turn that on. Settings › Updates & restore points puts an earlier set back. It saves the files in use first, so even that can be undone.
  • Settings a Linux update resets. A Linux update replaces linux.img, which puts things like SSH keys, a static IP or the host name back to stock. Update guard keeps copies and lists what went back, and only restores them when you ask.

Restore points are kept on the SD card in phosphor/restore-points (the newest 3, each file stored once however many points use it), and the settings copies in phosphor/guard. Files Phosphor installs itself are never part of them. Nothing is rolled back or restored by itself.

Video and DIP switches

How does trying a video setting work?

In Settings › Video on the TV, or the Video section of Phosphor for Windows, pick a setting and try it. It stays for 35 seconds: press Keep to keep it, or do nothing and the old one comes back by itself. If you get no picture, just wait. If the power goes during a try, the old setting comes back at the next start.

MiSTer.ini is backed up before every try, and Earlier settings brings an older version back. Modes that need a DIP switch changed say which one.

Why 35 seconds?

Many TVs take several seconds to lock on to a new signal, which left too little time to reach Keep.

Why does the SuperStation have its own ini files? Did Taki change the video pinout?

No pinout change. The SuperStation One has its own analog video hardware: a Sony CXA video encoder for S-Video and composite, and four DIP switches. The Sony encoder needs vga_mode=subcarrier in MiSTer.ini; with MiSTer's own default (rgb) there's no colour over S-Video or composite. So Taki Udon ships MiSTer.ini plus four profiles for the other kinds of output:

Filevga_modecomposite_syncvga_sogFor
MiSTer.inisubcarrier10HDMI, plus S-Video/composite through the Sony encoder
MiSTer_RGHV.inirgb00RGB with separate sync (VGA monitors)
MiSTer_RGsB.inirgb10RGB with composite sync (SCART); DIP 4 down adds sync on green
MiSTer_SVID.inisvideo11The FPGA's own S-Video/composite (DIP 3 up)
MiSTer_YPbP.iniypbpr10Component

All five also set video_info=2 and logo=0.

Phosphor changed my video ini files. What did it do?

Once per SD card, when Phosphor is installed or updated (and on the SD card image), it sets the video lines above to Taki's settings, so the SuperStation's video hardware works the way it was made to. Only those lines (vga_mode, composite_sync, vga_sog, video_info, logo) are changed. Everything else in each file stays as it was, including your HDMI settings and per-core sections. A missing profile is added, and MiSTer_example.ini is renamed MiSTer_example.ini.txt (see the next question).

Copies of the files as they were are in phosphor/backup/video-ini-<date>, and phosphor/backup/video-ini-taki.done lists what changed. It won't happen again on that card, so you can change any of these settings back and they'll stay.

Why does Phosphor offer four video profiles when MiSTer offers three?

MiSTer's menu offers MiSTer.ini plus only the first three MiSTer_*.ini files it finds on the card. The SuperStation ships four profiles, so one was always hidden. MiSTer_example.ini (MiSTer's reference copy) counted as one too, which could hide two. Which ones were hidden depended on the order the card happened to list them.

Phosphor renames the example file and its version of MiSTer's Main offers all four profiles. Pick one in Settings › Video on the TV, or the Video section of Phosphor for Windows or Android. MiSTer's own OSD picker still shows three. SS1 Tool on a Console Mode SuperStation keeps three, as Taki has it.

Which DIP switches go with which video mode?

For units made after December 2025. Region: Down = NTSC, Up = PAL. "–" means that switch doesn't matter for the mode.

Video modeDIP 1DIP 2DIP 3DIP 4
S-Video / composite, Sony encoder (subcarrier)RegionRegionDownUp
S-Video / composite, FPGA (svideo, cvbs)RegionRegionUpUp
Component (YPbPr)–––Down
RGB with separate sync (RGHV)–––Up
RGB, sync on green (RGsB)–––Down

What each switch does: 1 is the S-Video/composite region, 2 the FPGA luma trap, 3 picks the FPGA or the Sony encoder for S-Video/composite, and 4 is sync on green.

My S-Video or composite picture is black and white

Either vga_mode=subcarrier is set and the core has no subcarrier support, or the core is missing from yc.txt. Flip DIP 3 up and use the SVID profile.

How do I set up a PAL CRT?

Set menu_pal=1, flip DIP 1 up, and set each core to PAL in its OSD menu.

SuperStation problems

My SD card got wrecked after running a "fix overlap" tool

Some SuperStation cards came with fix_sd_overlap.sh / exfat_fix_overlap. It misreads the correct partition layout as overlapping, and running it can destroy the card (SuperStation-Documentation #14). Delete it. If a card is already damaged, reflash it.

CRT output, WiFi or the ARM cores stopped working after a Linux update

The September 7, 2026 MiSTer Linux update (kernel 5.15 to 6.18) broke CRT modes, WiFi and the ARM cores (3S-ARM, Duke3D, Quake) on the SuperStation. It has since been fixed upstream: run the update again. If a Linux update reset one of your settings files, put it back from MiSTer & Linux backups.

Update All crashes when I use the "Link" (chip-id) option

That option crashes on the SuperStation. Leave it off.

My SuperStation reboots by itself, or has file system errors, with an NVMe drive

Gen 4 NVMe drives cause this. Use a Gen 3 drive.

Which power adapter should I use?

A single-port USB-C PD adapter that gives 9 V at 3 A. The Steam Deck adapter works. Don't share a multi-port charger with other devices, and don't use a Nintendo Switch 1 adapter.

I get no picture over HDMI from the dock

Plug the HDMI cable into the SuperStation itself. The HDMI-shaped port on the dock is an expansion port, not video out.

A core says "Unsafe Options" (PlayStation) or "Game Disc Is Unsuitable" (Saturn)

Reset that core's settings to their defaults in its OSD menu.

Update All warns about deprecated ini settings

Replace your ini files with the updated ones in Taki Udon's SuperStation-Documentation INI_Files.

Getting help

Where do I report a problem?

Problems with Phosphor or Phosphor for Windows: the Phosphor OS Discord (#help, or #bug-reports for something broken) or GitHub issues, with what you did and which version you're on. Problems with the SuperStation itself (hardware, a core, a game) go to the Taki Udon Discord.
